How it works

chess.js is open source (BSD-2-Clause). It provides the rules, not a GUI. This file keeps a small custom HTML/CSS board.

One HTML file, with chess.js 1.4.0 loaded from jsDelivr. Internet is required to load the rules library. No accounts, UI frameworks, animation loop, signaling server, or game server. Both players must open this updated HTML in a modern browser and keep it open.

Moves travel over an encrypted WebRTC data channel. STUN only helps discover a route; there is no TURN relay. Some firewalls or NATs block direct connections. Try the same Wi-Fi or another network.

Includes castling, en passant, promotion, checkmate, stalemate, automatic threefold/50-move draws and insufficient-material draws, all handled by chess.js. No clocks, reconnect, or saved games. A new connection starts a new game.
